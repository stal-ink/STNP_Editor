## 编码陷阱（实现约束）

1. **C 独占不得只改顺序。** `stnp_instances.c.j2` 的 `STNP_Notify_Dispatch` 必须在调用 `<Module>_NotifyDispatch` **之前**检查 `<Module>_NotifyCallbackIsEnabled()`。原因：`NotifyDispatch` 在 enable 关闭且码已知时仍返回 `STNP_OK`。
2. **C 未知码才落入全局。** 模块返回 `STNP_ERR_COMMAND` 是唯一允许 fall through 的值。已知码 Decode 失败必须原样返回，禁止全局。
3. **C 全局不加 Enable。** 保留 Core weak `STNP_Notify_Callback` 与 Implementation 强符号。
4. **Python `_dispatch_notify` 开头必须保留 `if not DR: return`。** 在 trace / 认领 / 全局之前。DR 关 typed 与 `@stnp.on_notify` 都不投递。禁止把 DR 收窄成只门控 typed。
5. **Python 认领判定先于 decode。** `resolve` 为 `None` 时禁止为模块路径 decode，全局必须走 raw 形 `(instance, code, result, raw bytes)`，禁止传 dataclass / `NotificationDescriptor`。
6. **Python 全局 0.9.1 只有两种 raw 形。** 未知实例：`(source_id, code, result, raw)`；已知实例：`(instance, code, result, raw)`。
7. **C 测试** `test_notify_global_and_typed_callbacks_are_deferred_and_enable_semantics_hold`（与 01 完全一致，禁止只改后半段）：
   - 第一帧、未 Enable、`STNP_Dispatch` 之后：`g_raw_count==1 && g_typed_count==0`
   - Enable 后再发一帧、`STNP_Dispatch` 之后：`g_raw_count==1 && g_typed_count==1 && g_value==0xBEEF`
   禁止再断言 `raw==2`。另加 Python：DR 关 + typed 与 `on_notify` 均为 0。
   **禁止**假设 C enable-off 与 Python「已有 typed func」行为相同。Python 无 `NotifyCallbackEnable`。
8. **未知帧两道闸。** `SetCallback` 与 `Enable` 都要。缺一则真零调用。SOF 另有第二开关，默认关，不是主开关。
9. **C `UNKNOWN_NOTIFY` 禁止触发。** 枚举保留。
10. **C 不可路由 Task：** 在 `_try_complete_frame` 里，`EnqueueTask` 失败且不是 `STNP_ERR_BUFFER` 时，**shift 之前** `Report(TASK)`。队列满：禁止 Report，禁止 shift。
11. **Python SOF 必须逐字节滑。** 禁止 `del buffer[:-1]` 与 `del buffer[:offset]`。`unknown_report_sof` 打开且两闸都开时，回调次数 = 丢掉字节数。喂 `N` 字节且无协议 SOF、最后 1 字节保留：回调 **必须** `N-1` 次（02 测试点 5）。
12. **用户 unknown 回调异常必须隔离，禁止增加 `callback_errors`。** 未知 target/cmd 不再 `raise ProtocolError`。隔离 **必须**在 `_report_unknown` 内部。允许 `logging.exception`，**不是**正确性要求。
13. **IRQ：`STNP_Transport_Receive` 只拷贝。** 唯一允许的附加是 `STNP_BP_RX_COPY`（在 `g_rx_tail` 发布之后），trap 必须极短。
14. **`PARSE_RESYNC` 禁止打进 SOF 猎寻 `continue` 循环。** 只打 return 式 LEN/CRC。
15. **`STNP_BP_ENQUEUE` / `ROUTE_FAIL` / `DISPATCH` 必须写在 `stnp_runtime.c.j2`，禁止漏文件。**
16. **`ON_NOTIFY` 只插在 A 之后的 `stnp_instances.c.j2` 实际认领路径，一帧最多一次。** 禁止在 0.9.0 并行的全局+模块各打一次。Enable 后独占 Notify：`ON_NOTIFY` 次数 **必须**恰好 1（04 测试点 4；切片 C 测试必须出现）。
17. **`@stnp.trace.format(path)` 只登记 formatter，禁止写入 yaml 名单。**
18. **Task 顺序：`decode → validate → format.maybe → fn is None 检查 → fn()`。** validate 失败禁止 format。format 必须在 `fn is None` 之前。`LOG.warning` 文本 **必须**是 `"received unimplemented command %s.%s on %s"`。
19. **Notify format：认领 typed 与全局 fallback 各打实际走的那一条一次。** 全局 fallback **必须**调用 `format.maybe`：`TraceCmd(kind="notify", descriptor=None)`，payload **必须**是 `frame.payload`（`bytes`）。认领路径 payload 是 decode 结果或 `None`。无人认领禁止 format。`payload is None` **禁止**跳过 maybe；`default_format` 省略字段段。bytes payload **必须** hex。
20. **Runtime 必须恰好** `from .trace import debug as trace_debug, format as trace_format`，禁止 `import stnp`，禁止「或等价」。切片 C 即使尚未调用 `maybe`，禁止删掉 `format as trace_format`。
21. **C `STNP_DEBUG` 只允许 0/1。** 测试必须编两次。golden 按 0 生成。默认禁止 BKPT。trap 为 weak；测试提供强符号计数。
22. **禁止** log envelope、`STNP_LOGE`、`on_log`、第三 SOF。
23. **`parse_resync` 切换（禁止叠加）。** 切片 C：**必须**用计数器增量——每次 `feed()` 若本轮 `crc_errors`/`protocol_errors` 增加，打恰好一次，禁止按字节打，禁止用累计 `> 0`。切片 B：**必须**删除该计数器路径，改为每个 `ParseError("len"|"crc")` 一次。SOF ParseError 禁止打。
24. **`ParseError` 禁止 `Dispatcher.put`，禁止 `rx_frames++`。**
25. **Python LEN `header` 必须等于** `protocol.task_fixed_size` / `notify_fixed_size`（= C `STNP_TASK_FIXED_SIZE` / `STNP_NOTIFY_FIXED_SIZE`）。`ParseError("len").data` **必须** `bytes(self.buffer[:header])`。buffer 短于 header：**禁止**报 LEN。
26. **unknown 数据。** Notify：`frame.raw` 非空 **必须**用 `raw`；仅 `raw` 为空才允许合成 concat。Task 同：非空用 `raw`。C `STNP_UnknownFrame_Report`：**禁止** `data==NULL && length>0`。
27. **合法协议帧（含业务 Notify）即使 unknown enable 也禁止进 unknown 回调**（02 测试点 8）。Python：无 `on_notify` + 未知 notify → 1 次 `notify`；有 `on_notify` → unknown 0、全局 1（02 测试点 6）。
28. **emitter 所有权（禁止「若 C 未加则 D 加」）。** 切片 C：`emit/python/emitter.py` **必须**把 `trace.py` 加入 `stnp/core/` 生成列表。切片 D：**必须**加 `config/trace.yaml.j2`。C 的 `trace.py` **必须**已暴露 `format` 对象。
29. **`@stnp.on_unknown_frame` 只赋值 `_unknown_callback` 并 return fn，禁止自动 enable。** `_report_unknown` 内部两闸；关或 callback 为 None 立即 return；用户异常隔离且禁止 `callback_errors++`。reason `"sof"` 在 SOF 上报关闭时调用方禁止调用。
30. **切片 C 允许 `init()` 暂不 `load()` yaml；切片 D 的 `stnp.init()` 必须开始调用 `trace.load()`。** D 之前 `debug.enabled` 只经 `configure()` 或属性。
