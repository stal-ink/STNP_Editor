## 4. 命名与结构规则（统一）

1. **非 archive 的目录与文件**：全小写 + 下划线，可用两位数字前缀标章节顺序（`01_`…`08_`）；章节级文件用数字前缀，领域内文件不加前缀。目录索引一律命名为 `README.md`（固定大写，唯一例外）。
2. **每个非 archive 目录必须有 `README.md`**。archive 目录以顶层 `archive/README.md` 统一登记，**不**为每个版本目录新建 README；若目录内已有历史 `README.md`（v0.9），保留原样。
3. **章节编号与文件名一致**：`01`→`08`；总索引 `README.md` 不编号。
4. **每篇文档结构**：唯一 H1、H2 章节、H3 子节；页脚统一为一行导航：`[← 上一章](相对路径) | [文档目录](相对路径) | [下一章 →](相对路径)`（索引页只保留必要的"下一章"链接）。
5. **链接规则**：一律使用相对路径；禁止绝对路径与仓外文件链接（http/https 外链可选）。所有链接目标必须真实存在于磁盘（archive 正文除外，见 §13 第 2 条）。重命名后必须同步更新链接目标（只改目标，不改链接文字）。
6. **死链处置优先级**：① 指向新路径；② 指向同义现存页；③ 若目标已不存在且无同义页，降级为纯文本（保持句子通顺），并在执行记录中登记。
7. **不做的事**：不新增编号章节、不改 01–08 的顺序含义、不给 archive 正文加页脚或改标题。

## 5. 归档规则（`docs/archive/`）

### 5.1 判定依据（按顺序适用）

1. **文档正文自称的基线/目标版本**优先（例如正文写"0.2.0 中存在……"即归 `v0.2/`）。
2. 正文无版本标记时，用文档头部"归档横幅"中提到的版本（例如"可能与当前 0.5.0 修复版冲突"→ `v0.5/`）。
3. 仍无法判定 → 放 `archive/` 顶层，并在登记表说明"版本待人工裁定"。
4. **协议版本 ≠ 发行版本**：以协议版本命名的历史文档（`PROTOCOL_STNP_V1.0.md`）留 `archive/` 顶层，单独说明。
5. `docs/0.9/**` 与 `docs/方案/_superseded/**` 均为 0.9 期过程资料 → `archive/v0.9/`（用户明确要求）。
6. **archive 正文不改**：只移动、只登记；编号、术语、错别字、内部链接一律保持原样。

## 附录 A：相对链接检查脚本（Python）

用途：验收第 2 条。放在仓库根运行：`python check_docs_links.py`。
规则：跳过 http/https/mailto/纯锚点；跳过 `archive/` 下除 `README.md` 以外的历史正文；目标必须真实存在。

```python
"""docs 相对链接检查：报告不存在的相对链接目标。"""
from __future__ import annotations

import re
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent
LINK = re.compile(r"!?\[[^\]]*\]\(([^)]+)\)")


def is_historical_archive(p: Path) -> bool:
    parts = p.relative_to(ROOT).parts
    return "archive" in parts and p.name != "README.md"


def check(md: Path) -> list[str]:
    bad: list[str] = []
    for match in LINK.finditer(md.read_text(encoding="utf-8")):
        target = match.group(1).strip().strip("<>")
        if target.startswith(("http://", "https://", "mailto:", "#")):
            continue
        target = target.split("#", 1)[0].split("?", 1)[0]
        if not target:
            continue
        resolved = (md.parent / target).resolve()
        if not resolved.exists():
            bad.append(f"{md.relative_to(ROOT)} -> {target}")
    return bad


def main() -> int:
    files = [p for p in (ROOT / "docs").rglob("*.md") if not is_historical_archive(p)]
    if (ROOT / "README.md").is_file():
        files.append(ROOT / "README.md")
    bad: list[str] = []
    for f in files:
        bad.extend(check(f))
    if bad:
        print(f"BROKEN LINKS: {len(bad)}")
        for line in bad:
            print("  " + line)
        return 1
    print("OK: 0 broken relative links")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

## 附录 B：命名检查脚本（Python）

用途：验收第 1 条。放在仓库根运行：`python check_docs_naming.py`。

```python
"""docs 命名检查：非 archive 目录/文件必须全小写 + 下划线；只允许 README.md。"""
from __future__ import annotations

import re
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent / "docs"
DIR_OK = re.compile(r"^[a-z0-9_]+$")
FILE_OK = re.compile(r"^(README\.md|spec_0\.9\.md|[a-z0-9_]+\.md)$")  # spec_0.9.md 为明示例外（版本号入名）


def main() -> int:
    bad: list[str] = []
    for item in sorted(ROOT.rglob("*")):
        rel = item.relative_to(ROOT)
        if "archive" in rel.parts:
            continue
        if item.is_dir():
            if not DIR_OK.match(item.name):
                bad.append(f"DIR  {rel}")
        elif not FILE_OK.match(item.name):
            bad.append(f"FILE {rel}")
    if bad:
        print(f"NAMING VIOLATIONS: {len(bad)}")
        for line in bad:
            print("  " + line)
        return 1
    print("OK: 0 naming violations")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
